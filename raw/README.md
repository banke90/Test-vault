# raw/

Scratch notes. In-progress thinking, "haven't read this yet" stubs, fragments captured before they decay. Explicitly **not verified**, explicitly not for understanding.

The discipline is opposite to the rest of the vault. Notes under `notes/` and entries under `facts/`, `ops/`, `primers/`, `lessons/` are about things I have settled on. Files in `raw/` are about things I have *not* settled on — and the format is loose because pretending otherwise would make me wait until I had clean thoughts before writing anything down, which is exactly the failure mode this directory exists to prevent.

## What goes here

- **Pre-reading stubs.** "Page 2020 — haven't read yet, but the abstract says X; if true, this would update [[foo]] in the following way." Useful for queueing reading without losing the trigger that made me want to read it.
- **In-flight thoughts.** A surprise from a paper, an objection I want to think about more before committing, a connection between notes I'm not sure of yet.
- **Fragments.** A diagram, a quote, a question that's bothering me but isn't yet a `Questions I'd like answered` entry in any note.
- **Drafts.** A note I'm working toward but haven't finished. When the draft is ready, promote to `notes/` and delete the raw original (or leave a one-line stub pointing forward).

## What does NOT go here

- Anything I'd stand behind. That belongs in `notes/`, with proper sources and a [Confidence] tier.
- Anything I'd want to *find* via grep when looking up a fact. That belongs in `facts.md`.

## Format

Loose. A title, a date, prose. Maybe a `[Status: WIP]` marker. No required sections.

If a raw note has the same title as a polished note (e.g. drafting toward a real note), prefix the raw filename with `draft-` to avoid wikilink collisions.

## Aging-out rule

Anything older than ~3 months that hasn't been promoted is either deleted or accepted as a permanent fragment. Permanent fragments stay because they capture a specific question or surprise that's still alive. If I look at one and can't reconstruct what made it interesting, delete it.

The point of `raw/` is to be the antidote to a vault made entirely of polished essays. If I never have anything in here, I'm probably suppressing thoughts before they can be examined.
